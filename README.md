Trainer Diary Pro (PWA)
Анотація та науково-педагогічне призначення
Trainer Diary Pro є спеціалізованим науково-методичним прогресивним вебзастосунком (Progressive Web Application), розробленим для цифровізації освітнього процесу підготовки майбутніх тренерів з обраних видів спорту у закладах вищої освіти.

Застосунок поєднує інструментарій суб'єктивного самоконтролю функціонального стану студентів (шкала RPE, оцінка втоми, сну, м'язового болю), стандартизовані випробування рухових якостей (тести бігової та силової витривалості, координації) та систему виконання індивідуальних завдань із використанням механік академічної гейміфікації (XP, бейджі, лідерборди). Для викладача реалізовано модуль аналітичного моніторингу групи з автоматичним розрахунком квартильного рейтингу та вивантаженням масивів даних у форматі CSV.

Відповідність принципам FAIR для дослідницького ПЗ
Findable: Код оснащено стандартизованими метаданими у форматі Citation File Format (CITATION.cff), відкритим маніфестом та постійним цифровим ідентифікатором DOI, що генерується Zenodo.

Accessible: Використання відкритого протоколу поширення вихідного коду, клієнтської архітектури на основі стандартних вебтехнологій без прив'язки до пропрієтарного середовища збірки та підтримка режиму Offline-First через Service Worker.

Interoperable: Експорт аналітичних зрізів моніторингу у відкритому форматі CSV із підтримкою кодування UTF-8 (BOM) для прямого імпорту в пакети біометричного та статистичного моделювання (R, Python, SPSS).

Reusable: Код розповсюджується під пермісивною ліцензією MIT, що гарантує можливість вільного повторного використання, адаптації та верифікації методики.

Архітектура та стек технологій
Фронтенд: HTML5, CSS3 (Modern Responsive Flexbox/Grid UI), Vanilla JavaScript (ES-модулі).

Серверна частина та база даних: Google Firebase Ecosystem (Firebase Authentication, Cloud Firestore).

PWA-компоненти: Web App Manifest (manifest.json), Service Worker (sw.js) для фонового кешування ресурсів.

Інструкція з локального розгортання
Клонувати репозиторій або завантажити вміст каталогу.

Для коректної роботи Service Worker відкрити кореневу папку за допомогою будь-якого локального вебсервера (наприклад, Live Server у VS Code, npx serve або локального сервера Python python -m http.server 8000). Відкриття файлу безпосередньо через протокол file:/// блокує функціонування Service Worker з міркувань безпеки браузера.

Відкрити браузер за адресою http://localhost:8000.
